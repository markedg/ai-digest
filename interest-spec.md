# Interest spec

The reader is a senior software engineer who ships production code with AI tools daily (Claude Code in particular). Pick videos that genuinely move his understanding forward.

## Priority topics

- **Frontier LLM work** — new flagship or open-weights releases, capability surprises, benchmark/eval results, post-training and reasoning advances.
- **Agentic systems** — coding agents (Claude Code, Cursor, Devin, etc.), agent benchmarks (SWE-bench, etc.), multi-agent systems, computer use, tool-use research, agent design patterns.

## Welcomed formats

Any of these are fine, judged on substance not polish:

- Technical paper walkthroughs
- Well-sourced news & announcement coverage
- Hands-on demos where someone actually builds with the new thing
- Substantive industry analysis (strategy, competitive dynamics, where the field is heading)

## Filter out aggressively

- "How to use ChatGPT for productivity" / AI-for-non-technical-audiences content
- AI doom / existential-risk-vibes content that's more anxiety than substance
- Intro-level explainers (what is an LLM, what is RAG) — the reader already knows this
- Low-information-density reaction/hype videos even if popular — judge by signal density, not view count alone
- Non-English videos — the reader only watches English-language content

## Official lab content

Official channels (Anthropic, OpenAI, Google DeepMind, Meta AI) are welcome **when** substantive — technical talks, paper walkthroughs, deep demos. Skip pure marketing keynotes and hype reels even from official sources.

**Practical applied content about Claude Code, MCP, agent workflows, and tool integrations IS in scope** even in tutorial/walkthrough form — the reader uses these tools every day, so "how MCP works," "the CLAUDE.md file," "new agent dashboard," "I tested 3 ways to deploy Claude agents" type content is signal, not intro-level fluff. The "intro explainer" exclusion applies to what-is-an-LLM/transformer/RAG basics, not to feature walkthroughs of tools the reader actively uses.

## Conference talks

Talks from AI/ML conferences and dev events (Code with Claude, AI Engineer summit, NeurIPS, ICML, KubeCon AI tracks, etc.) are welcome and should be scored generously when from credible speakers (researchers, practitioners, lab employees). These are typically high signal-density.

## Depth calibration

Assume working knowledge of transformers, RAG, fine-tuning, evals. Paper-level math is welcome but not required. Prefer signal density over runtime — a 6-minute video that nails it beats a 45-minute one that meanders.

## Time window

Surface both *fresh-and-popular* (last 24–48h with high views) and *still-climbing* (last 7 days, sustained attention). Dedup overlaps. The goal is "what should I know about today," not strictly "what just dropped."
